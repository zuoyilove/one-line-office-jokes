One single-line joke about office life: someone hits reply-all to beg everyone to stop replying all, and the whole office agrees with them — one reply-all at a time. It turns on a real detail of office life and lands its laugh in the last few words.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` — 120 characters on a single line, inside the 1–199 character gate.
